TaskWatch is a watch / timer that can sit on top of other applications and record the time spent on doing tasks. It shows previous task history and daily, weekly and monthly summaries. Customizable appearance.

Hotkeys
- Space: Start / Pause task timer
- Ctrl+Space: Stop and record task
- Num+ / = scale up
- Num- / - Scale down
- C: Toggle show system time
- L: Show list
- S: Show settings
- Esc: hide buttons
- M: Minimize app
- Ctrl+R / F5: Reset position
- Alt+Enter / F11: resize to screen, if timer is constrained to a box smaller than the screen
